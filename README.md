
# ☕ Café Sales — Data Cleaning & Exploratory Data Analysis

**An end-to-end Python analytics project that turns messy café transaction data into trustworthy business insights.**

## 📊 Project Overview

This project explores a synthetic dataset of **10,000 café transactions from 2023**, intentionally containing missing values, inconsistent data types, and invalid entries.

Using Python, I clean and validate the data, perform exploratory data analysis (EDA), build visualizations, and turn the findings into actionable recommendations.

**Workflow:** Data Profiling → Cleaning → Validation → EDA → Business Recommendations

## 📈 Key Results

| Metric | Result |
|---|---:|
| Original records | 10,000 |
| Clean transactions | 9,514 |
| Total revenue | $84,868.50 |
| Average transaction value | $8.92 |
| Highest-revenue item | Salad — $18,220 |
| Best-selling item | Coffee — 3,766 units |
| Highest-revenue month | June — $7,353 |
